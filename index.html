  var tg = window.Telegram && window.Telegram.WebApp;

④ 如何接到真实机器人（Bot API 10.4）

  • 用 BotFather 创建机器人，确认 Bot API 版本 ≥ 10.4。
  • 通过 sendMessage 的组件字段下发这段 HTML（见 bot-payload.json 示意）。
  • 需要真实钱包数据时，在 onclick 内接入 TON Connect：window.Telegram.WebApp 已就绪。
  • 按钮触发的「仅你可见」临时回复由 Telegram 端原生处理，无需额外后端。

完整协议字段以 Telegram 官方 Bot API 10.4 文档为准；本 Demo 以结构示意 + 可交互 UI 呈现核心能力。
